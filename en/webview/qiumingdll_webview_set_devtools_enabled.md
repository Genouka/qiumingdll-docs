# qiumingdll_webview_set_devtools_enabled(webviewId, enabled)

Enable or disable developer tools (F12 DevTools) support for the specified WebView.

## Signature

```gml
qiumingdll_webview_set_devtools_enabled(webviewId, enabled)
```

## Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| webviewId | Real | yes | WebView id, range 1 ~ 16 |
| enabled | Real | yes | Boolean switch: 1 (non-zero) = enable DevTools, 0 = disable |

## Returns

| Value | Description |
|----|------|
| 1 | Set successfully |
| 0 | Call failed: invalid id, the WebView does not exist, or it is **not ready yet** (this function requires readiness; wait until get_is_active returns 1) |
| 0 | Non-Windows platform: the GML wrapper returns 0 directly |

## Usage

- Precondition: the WebView has been created and is **ready** (this switch writes a WebView2 setting; calls made before readiness return 0).
- **Off by default**: after create, DevTools is disabled (unlike scripts and the context menu, which default to on).
- Debugging advice: enable it right after readiness during development; do not enable it in release builds, otherwise players can open developer tools to inspect or tamper with page content.
- Once enabled, press F12 in the window or right-click -> Inspect to open the DevTools panel; this pairs well with dynamic content generated by execute_script.
- Affects only this WebView, not other windows.

## Example

```gml
/// Create event (obj_webview_dev)
qiumingdll_webview_init();
webviewId = qiumingdll_webview_create(200, 150, 800, 600);
devMode = false;   // e.g. read from ini: devMode = ini_read_real("config.ini", "Debug", "devtools", 0)

/// Step event
// Once ready, decide whether to enable DevTools according to the config
if (qiumingdll_webview_get_is_active(webviewId) == 1 && !configured)
{
    configured = true;
    if (devMode)
    {
        qiumingdll_webview_set_devtools_enabled(webviewId, 1);
        show_debug_message("Dev mode: DevTools enabled");
    }
    qiumingdll_webview_navigate(webviewId, "https://example.com");
}

// Press F9 at runtime to toggle temporarily
if (keyboard_check_pressed(vk_f9))
{
    devMode = !devMode;
    qiumingdll_webview_set_devtools_enabled(webviewId, devMode ? 1 : 0);
}

/// Room end event
qiumingdll_webview_cleanup();
```
