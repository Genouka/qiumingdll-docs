# qiumingdll_json5_encode(value)

Serializes GameMaker data structures (DS Map / Array / primitive types) into a JSON5 string. On Windows it prefers the DLL implementation; on non-Windows platforms it falls back to `json_encode`.

## Signature

```gml
qiumingdll_json5_encode(value)
```

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| value | DS Map / Array / Real / String | yes | The data to serialize. A DS Map may contain nested Array, DS Map, Real, String and Bool values |

## Returns

| Value | Description |
|-------|-------------|
| String | The serialized JSON5 text. Generated by the DLL on Windows when initialized; otherwise the output of standard `json_encode` |

## Usage

- Preconditions: on Windows, call `qiumingdll_init()` first; if it has not been initialized, or on a non-Windows platform, the function falls back to `json_encode(argument0)`.
- Platform limits: the DLL path is available only on Windows.
- Behavior details: the function first converts the GML data to standard JSON text with `json_encode` and passes it to the DLL, which then produces the final result.
- Can be used together with `qiumingdll_json5_decode` to store and load data with comments.

## Example

```gml
var data = ds_map_create();
ds_map_add(data, "name", "qiuming");
ds_map_add(data, "version", 42);
ds_map_add_list(data, "tags", list);

var str = qiumingdll_json5_encode(data);
show_debug_message(str);
ds_map_destroy(data);
```
