# qiumingdll_winsplit_set_shape_from_bitmap(splitId, bitmapPath, transColor)

Use a bitmap (BMP) as a shape mask for a split window: pixels whose color equals `transColor` become transparent (holes) in the window, while all other pixels remain visible.

## Signature

```gml
qiumingdll_winsplit_set_shape_from_bitmap(splitId, bitmapPath, transColor)
```

## Parameters

| Parameter | Type | Required | Description |
|------|------|------|------|
| splitId | real | yes | Split window ID, in the range 1 ~ 16; the window must exist |
| bitmapPath | string | yes | Path to a BMP file (a real path on disk, not a resource name). Using `working_directory + filename` is recommended; Chinese paths are supported |
| transColor | real | yes | Transparent color in `0xRRGGBB` format (red, green, and blue each 0~255, 24 bits total); pixels exactly equal to this color become transparent |

## Returns

| Value | Description |
|----|------|
| `1` | Shape applied successfully: the image was loaded, the transparent color was detected, and the region was generated |
| `0` | Failure: `splitId` is invalid or does not exist, the bitmap file could not be loaded (wrong path or not a BMP), etc.; on non-Windows platforms the wrapper returns `0` directly |

## Usage

- Prerequisite: `qiumingdll_winsplit_init()` has been called successfully, and the split window identified by `splitId` exists.
- Only BMP files are supported. On load failure the function returns `0` and leaves the window's previous shape unchanged.
- The alpha part of `transColor` is ignored; only RGB (the low 24 bits) is compared. Examples: magenta `0xFF00FF`, black `0x000000`.
- The image may be smaller than, equal to, or larger than the window. The shape is generated by scanning the image pixels row by row; non-transparent areas of the image become the shape's visible area on the window.
- The shape does not update automatically when the window size changes. After changing the window size with `set_size`, call this function again.
- This shape replaces any previously set shape; `qiumingdll_winsplit_clear_shape` restores the rectangle.
- Suitable for custom-shaped windows (stars, character silhouettes, arbitrary graphic UIs). The art side only needs to prepare a BMP with a solid-color background.

## Example

```gml
// In the Step event of a controller object: press B to clip split window 1 with a five-pointed-star template
if (keyboard_check_pressed(ord("B")))
{
    // mask.bmp: the star is white and the background is magenta (#FF00FF); the magenta area becomes transparent
    var _bmp = working_directory + "star_mask.bmp";
    if (file_exists(_bmp))
    {
        if (qiumingdll_winsplit_set_shape_from_bitmap(global.split_1, _bmp, 0xFF00FF) == 1)
            show_debug_message("Star shape applied; the magenta background is now transparent");
        else
            show_debug_message("Failed to apply bitmap shape: check that the file is a BMP and the path is correct");
    }
}
```
