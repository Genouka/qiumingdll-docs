# winsplit Module

Multi-window split display: present the contents of one window on several screens at the same time, with shape clipping, source region scaling and batch animation control.

65 functions in total.

## Function index

| Function | Description |
|------|------|
| [qiumingdll_winsplit_add_path_point](qiumingdll_winsplit_add_path_point.md) | Appends a path point (screen coordinates) to the path list of the given split window; the points can then be used with move_path / move_path_animate. |
| [qiumingdll_winsplit_add_shape_point](qiumingdll_winsplit_add_shape_point.md) | Adds a vertex to the polygon shape currently being recorded, between begin_shape and end_shape. |
| [qiumingdll_winsplit_batch_add_position](qiumingdll_winsplit_batch_add_position.md) | Adds a "move position" command to the batch recording: during playback the window interpolates from its current position to the target position (x, y) within durationMs milliseconds. |

| [qiumingdll_winsplit_batch_set_easing](qiumingdll_winsplit_batch_set_easing.md) | Sets the easing curve used by subsequent commands (batch_add_*) in the batch recording of the given split window. |
| [qiumingdll_winsplit_batch_set_src_anim_mode](qiumingdll_winsplit_batch_set_src_anim_mode.md) | Sets the source animation mode used by subsequent size-related commands (batch_add_size / batch_add_region) in the batch recording of the given split window. |
| [qiumingdll_winsplit_batch_step](qiumingdll_winsplit_batch_step.md) | Advances the "frame-sync" batch animation of the given split window by one frame (only effective for playback started by batch_play_frame_sync) and returns whether playback is still running. |
| [qiumingdll_winsplit_batch_stop](qiumingdll_winsplit_batch_stop.md) | Stops the batch animation currently playing on the given split window midway; the window stays in the state it had when stopped. |
| [qiumingdll_winsplit_begin_shape](qiumingdll_winsplit_begin_shape.md) | Starts recording a custom polygon shape for the given split window: clears the shape point buffer of that window, then add points one by one with add_shape_point and build the shape with end_shape. |
| [qiumingdll_winsplit_cleanup](qiumingdll_winsplit_cleanup.md) | Cleans up the whole window splitting module: destroys all split windows, restores the original game window display and uninstalls the capture and message hooks. | [qiumingdll_winsplit_clear_path](qiumingdll_winsplit_clear_path.md) | Stops the animation playing on the given split window and clears all of its added path points. |
| [qiumingdll_winsplit_clear_shape](qiumingdll_winsplit_clear_shape.md) | Clears the shape region of the given split window and restores the full rectangle (the whole client area picture is shown). |
| [qiumingdll_winsplit_create](qiumingdll_winsplit_create.md) | Creates a split window: displays a pixel region (source region) of the original game window client area in real time in a new top-level window, and returns the split window ID. |

| [qiumingdll_winsplit_end_shape](qiumingdll_winsplit_end_shape.md) | Ends shape recording and applies the collected polygon vertices to the split window: the window immediately becomes that polygon shape, and areas outside the polygon are no longer displayed. |
| [qiumingdll_winsplit_exists](qiumingdll_winsplit_exists.md) | Checks whether the given split window ID is valid (created and not yet destroyed). |

| [qiumingdll_winsplit_hide](qiumingdll_winsplit_hide.md) | Hides the given split window without affecting its internal state; it can be shown again at any time with show. |
| [qiumingdll_winsplit_hide_original](qiumingdll_winsplit_hide_original.md) | Hides the original game window while split windows keep displaying the picture, for the typical window splitting use case of "only the split windows show, the main window does not". |
